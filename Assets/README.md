# Application icon

`icon-master.png` is the transparent source artwork for the application and active tray icon. `icon-waiting.png` is its deliberately muted waiting-state variant. Both ICO files contain 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel PNG frames.

The source concept was generated with the built-in OpenAI image generation tool and then converted to a transparent, size-normalized production asset. The prompt asked for an independent, flat, vector-like speech bubble with vertical up/down navigation, bold geometry, cobalt and cyan colors, no text, no third-party brand marks, and strong readability at 16 pixels.

When changing the artwork, preserve the transparent padding, multi-size ICO frames, and the clear visual difference between the active and waiting states.
